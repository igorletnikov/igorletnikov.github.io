Privacy policy

Effective date: 2026-11-04

shorts-factory is a private tool. Its owner uses it only for the owner's own YouTube channels: @threemindslab, @whyitbrokehistory and @whybuiltlikethat. Contact: CONTACT_EMAIL.

YouTube access and use

The app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The app requests these OAuth scopes:

  • https://www.googleapis.com/auth/youtube.upload — upload approved videos to the owner's channels.
  • https://www.googleapis.com/auth/youtube.readonly — read YouTube data, including public video research.
  • https://www.googleapis.com/auth/yt-analytics.readonly — read the owner's channel analytics.
  • https://www.googleapis.com/auth/youtube.force-ssl — update uploaded videos' publication status and schedule, set their thumbnails, manage the owner's playlists and channel branding, post one question comment on the owner's own videos, and read comments on those videos.

Uploads send video files, titles, descriptions, source links, tags, category, privacy and publication settings, and made-for-kids and synthetic-media declarations to YouTube. The app stores returned video IDs and publication records. Analytics reads views, average view percentage, average view duration, likes and comments counts, and subscribers gained for the owner's videos published in the last 30 days; it does not retrieve individual viewers' identities from analytics.

The app reads comment text and like counts on the owner's own videos, excluding the channel's own comments, to learn which topics and questions interest viewers.

Public research reads video IDs, titles, descriptions, channel names and IDs, view counts, subscriber counts, and thumbnail URLs and images to identify format and style patterns.

Storage and retention

The app's SQLite database (core/data/factory.db) and OAuth credentials (core/config/tokens.json) are stored on the owner's PC, not on this website. The database contains video and publication records, dated analytics snapshots, and recent comment text. Older comment text is deleted when the app's tracker runs. Other records and tokens remain until the owner manually deletes them; the current code has no automatic deletion after revocation. The 30-day analytics query window does not delete older snapshots.

Public research data is processed during each scout run. Downloaded thumbnails are removed when that processing ends, including on processing errors. Format and style notes and run history remain locally in channels/channel1/templates/scout.md and core/data/journal/scout_history.jsonl until manually deleted.

Data disclosure

The operator does not sell data or share it for advertising. Operation sends uploads and API requests to Google/YouTube. Research sends selected public video metadata and thumbnails to Anthropic's Claude through Claude Code for analysis, and links to public videos to Google Gemini. Script generation and learning send selected own-channel titles, performance metrics and recent comment text to Claude. Local storage therefore does not mean all processing stays on the PC; this policy does not promise a retention period for those providers' copies.

This static website has no scripts, cookies, forms, or analytics added by the app.

Revocation and deletion

You can revoke the app's Google access at any time through Google Account permissions. Revocation prevents further authorized access but does not erase existing local records or videos already uploaded to YouTube. Stop the app and manually remove its saved tokens and related local data, or contact CONTACT_EMAIL for deletion assistance. Uploaded videos can be managed separately in YouTube Studio.
